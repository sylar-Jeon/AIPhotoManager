# AI Photo Manager

## 1. 프로젝트 개요

**AI Photo Manager**는 사용자의 사진 라이브러리를 스캔하여 인공지능(AI)으로 사진을 자동 분류하고, 태그를 지정하여 앨범을 생성해주는 iOS 애플리케이션입니다. 이 앱을 통해 사용자는 수많은 사진을 손쉽게 정리하고 관리할 수 있습니다.

## 2. 주요 기능

- **사진 라이브러리 스캔**: 사용자의 사진첩에 접근하여 모든 사진을 가져옵니다.
- **AI 기반 자동 분류**: Core ML 모델(ResNet50)을 사용하여 사진의 내용을 분석하고, '인물', '동물', '음식', '풍경', '사물' 등의 카테고리로 자동 분류합니다.
- **자동 앨범 생성**: 분류된 카테고리를 기반으로 앨범을 자동으로 생성하고, 각 앨범에 해당하는 사진들을 정리합니다.
- **앨범 및 사진 관리**:
  - **앨범 목록 보기**: 생성된 앨범들을 그리드 또는 리스트 형태로 확인합니다.
  - **앨범 상세 보기**: 특정 앨범에 포함된 사진들을 썸네일 그리드로 확인합니다.
  - **사진 뷰어**: 사진을 전체 화면으로 확대하여 볼 수 있습니다.
- **앨범 편집**:
  - **이름 변경**: 앨범의 이름을 자유롭게 수정할 수 있습니다.
  - **앨범 병합**: 여러 앨범을 선택하여 하나의 앨범으로 합칠 수 있습니다.
  - **앨범 삭제**: 불필요한 앨범을 삭제할 수 있습니다.
  - **사진 이동**: 특정 사진을 다른 앨범으로 이동시킬 수 있습니다.

## 3. 기술 스택 및 아키텍처

- **UI/UX**: `SwiftUI`를 사용하여 선언적이고 현대적인 UI를 구축했습니다.
- **아키텍처**: `TCA (The Composable Architecture)`를 채택하여 단방향 데이터 흐름을 구현하고, 앱의 상태 관리를 효율적이고 테스트 용이하게 설계했습니다.
- **AI 및 이미지 처리**:
  - `Core ML`과 `Vision` 프레임워크를 활용하여 기기 내(on-device)에서 이미지 분류를 수행합니다.
  - `ResNet50` 모델을 사용하여 이미지의 특징을 추출하고 분류합니다.
- **사진 데이터 관리**: `Photos` 프레임워크를 사용하여 사용자의 사진 라이브러리에 안전하게 접근하고 데이터를 가져옵니다.
- **의존성 관리**: `Swift Package Manager (SPM)`를 사용하여 외부 라이브러리를 관리합니다.

## 4. 프로젝트 구조

프로젝트는 모듈화된 구조를 가지며, 각 모듈은 `AppPackage`라는 Swift Package 내에서 관리됩니다.

- **`Sources/APFoundation`**:
  - 앱의 핵심 비즈니스 로직과 데이터 모델을 포함합니다.
  - `PhotoClient`: Photos 프레임워크와의 상호작용을 담당합니다.
  - `AIPhotoClassifierClient`: Core ML 모델을 사용하여 이미지 분류를 수행하는 클라이언트입니다.
  - `Album`, `Photo`: 앱에서 사용되는 핵심 데이터 모델입니다.
  - `ImageClassificationService`: 실제 이미지 분류 로직을 처리하는 서비스입니다.

- **`Sources/Scenes`**:
  - 앱의 각 화면(Scene)에 해당하는 UI와 상태 관리 로직을 포함합니다.
  - `AlbumListView` / `AlbumListFeature`: 메인 앨범 목록 화면과 관련 로직입니다.
  - `AlbumDetailView` / `AlbumDetailFeature`: 앨범 상세 화면과 관련 로직입니다.
  - 각 피처(Feature)는 TCA의 `Reducer` 프로토콜을 준수하여 상태(State), 액션(Action), 리듀서(Reducer)로 구성됩니다.
